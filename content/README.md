# ICS 第一次小测复习讲义

这是一套从基础开始、以独立解题为目标的复习资料：五讲基础复习，加一讲测后补强。根据课程前8讲、教材相关小节、普通研讨题、小班材料及已核对的往年题重新编写，没有沿用此前生成的补充讲义。

推荐打开本仓库 `site/index.html` 阅读，或使用仓库 README 中的在线入口。正文、公式、代码与图表已排版，练习答案可按题展开。Markdown 是后续补充和更正的源稿。

**从第1讲开始，每次读完一个例题就自己重算，再继续往下。** 五讲对应五天任务，不要求每天固定学满某个时长；需要时可以多花时间修薄弱点。[完整复习计划](复习计划.md)保留了优先级和进度调整规则。

## 每次怎么学

1. 先读本讲开头的前置检查，不会的内容先标记。
2. 按知识点顺序读正文；图里的每一个箭头、槽位或偏移，尽量自己解释一次。
3. 示范例题先遮住后半段，尝试预测下一步，再核对完整过程。
4. 独立练习写过程，不边做边查答案。卡住可以直接提问，把题号和已有尝试一并发来。
5. 对照分点答案订正。获得提示后完成的部分记为练习，不倒填为首次独立得分。
6. 达标再选做；没达标先修具体错误，避免反复重读整章。

全套统一采用课程的x86-64、Linux、AT&T汇编与常见System V调用约定；题目另行指定的位宽、字节序或浮点格式优先。正文会区分机器指令效果、C语言规则和课堂简化前提。

## 学习中的问题与补充讲义

你可以在新对话中继续问。为让新对话准确找到这套资料，请在同一个ICS项目中提问，或附上本目录的路径，并说明正在读复习第几讲、哪个题号。仅凭项目外的一句“第一讲”无法可靠判断你指哪份文件。

处理顺序固定为：**先回答当前问题，再在同一轮把问题和解答补入对应文件。** 不需要每次重新要求收录；你明确说不收录时除外。

较长的补充会单独放在本目录的“补充讲义”子目录。例如，针对本套第1讲的追问收录到“第一讲后补充讲义.md”，并在主讲义相应位置加链接。具体规则见[补充讲义与问答记录方式](补充讲义/README.md)。只有出现真实提问后才创建对应正文，不预先编造疑问、答案或学习经历。

若发现主讲义的错误，直接更正正文并保留简短更正记录；解释性扩展放进后补充讲义。原始问题、后续追问、教材出处与助手补充会明确区分。

个人学习记录未包含在发布版中。
