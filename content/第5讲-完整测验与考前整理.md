## 1 开始前只做这几件事

使用2025 第一次阶段测验无答案版（来源资料未随仓库分发），共10个PDF文件页、24题。若选择独立模拟，先完成作答再展开答案；也可以按需逐题学习解析。若此前已经看过某道题的答案，在答卷上标“已见”，最后与未见题分开统计。

本地原卷没有注明考试时长，训练暂设120分钟；若老师已经公布实际时长，优先采用官方时长。限时内不查讲义、不运行代码、不请求提示；看不懂题面可以先标记。时间结束画一条分界线，之后补做的内容不能倒算为限时内得分。

开做前统一下面几处题面口径。这些是为了减少材料歧义，不是新增考试要求：

- 第3题“首字节”在本次训练中指**最低内存地址处的字节**。
- 第17题 `bit_not1(long a)` 内的 `~p` 改为 `~a`，`long y=~x` 后补分号。按课堂“取地址的变量需要可寻址存储、其他变量尽量用寄存器”的示意模型作答，不推断某一优化级别的真实编译输出。
- 第12题的子编号有跳跃，按原卷出现的空作答，不需要寻找不存在的第3问。
- 第18题内存操作数里印刷缺少的寄存器前缀 `%` 可自行补上。汇编填空按整行检查，不能把一行中的多个空重复计成多行。
- 第20题按课上给出的连续二维数组机器布局计算；不把此例当作可移植C跨行指针算术的证明。
- 第24题涉及旧材料的硬件前提。“引入执行权限检查是否需要硬件能力”与“已经支持该能力的机器是否要更换CPU”是两种口径。本次训练接受明确区分前提且解释正确的答案。

这些说明没有改写原PDF；均为本套复习训练的统一说明。

## 2 做卷时的固定方法

先快速浏览题型，直接拿下能确定的题；一题开始无进展时先写已知关系，再标记跳过。返回时优先处理“只差一步”的题。最后检查单位、位宽、signed/unsigned、寄存器宽度、十六进制进位、数组下标和答案填写位置。

**图5-1 做题时的判断流程。** 箭头表示下一步动作，遇到卡点时不必在原地反复猜。

```text
读题 -> 标类型/位宽/给定机器条件 -> 能列出第一步吗？
                                  | 是
                                  v
                         写公式、状态表或栈图
                                  |
                                  v
                         计算 -> 核对题目问的是值还是地址
                                  |
                                  v
                              填答并继续

“第一步也没有” -> 标记问题所在 -> 先做下一题 -> 最后一轮回看
```

不同题型的第一步尽量固定：

| 题型 | 第一笔写什么 |
|---|---|
| C整数表达式 | 每个操作数的类型，提升或转换后再比较 |
| 浮点 | s、exp、frac，以及属于哪一类编码 |
| 汇编片段 | 输入寄存器、输出寄存器、访问宽度 |
| 控制流 | cmp实际计算谁减谁，分支是有符号还是无符号 |
| 栈 | 当前rsp、每次push/call/pop/ret的变化 |
| 数组 | 首地址 + 元素大小 × 线性下标 |
| 结构体 | 每字段大小、对齐要求、放置前后的偏移 |
| 内存安全 | 起始地址、写入总字节数、目标位置偏移 |

## 3 本次训练的评分方式

原卷第5、6讲的逐空/逐行规则与分组总分不完全一致。为避免为了凑100分随意删题，这里先按“作答单位”记录，再按原卷各讲总分换算。这是**训练分**，不是重新宣称官方评分规则。

一个单位原则上得0或1；说明题只写对结论、缺少关键原因可得0.5。具体单位与答案在核对文件中列明。记第k讲得分单位数为c_k：

| 原课程讲次 | 题号 | 单位总数 | 训练分换算 |
|---|---|---:|---|
| 2 | 1—3 | 6 | 12×c₂/6 |
| 3 | 4—6 | 10 | 10×c₃/10 |
| 4 | 7—9 | 6 | 6×c₄/6 |
| 5 | 10—14 | 15 | 28×c₅/15 |
| 6 | 15—17 | 17 | 16×c₆/17 |
| 7 | 18—22 | 10 | 20×c₇/10 |
| 8 | 23—24 | 4 | 8×c₈/4 |

各组换算后相加，最后保留一位小数，满分100。第18、19题各两行汇编分别按两单位计；第23题完整输出是一单位；第24题每个待填行是一单位，已给出的示范行不计。

作答后再打开[保留卷核对与解析](答案/第5讲-保留卷核对与解析.md)。遇到题面歧义而做出合理解释时，写明依据再评定，不机械照抄旧答案。

## 5 纠错用的新题库

以下全部为助手补充，供测验后选取；不是额外要求把14题全部刷完。每组两题，选择最薄弱的两组，共四题。只看题面，做完后查[纠错题答案](答案/第5讲-纠错题答案.md)。

### A 整数与类型

- **D5-A1**：一个8位位模式为0x92。分别按无符号和补码解释；将补码值符号扩展到16位后，位模式是什么？
- **D5-A2**：在本课程32位int模型下，`int x=-3; unsigned u=2;`，判断 `x<u`，并写出比较前x对应的无符号数值。不要只回答真或假。

### B 浮点

- **D5-B1**：一种8位格式由1位符号、3位阶码、4位小数组成，bias=3，编码分类按IEEE式规则。位串`0 010 1000`表示什么数？`0 000 0010`又表示什么数？
- **D5-B2**：按最近偶数舍入，把二进制1.101100保留三位小数。说明为何需要或不需要进位。

### C 寻址与寄存器

- **D5-C1**：rax=0x200，rcx=5，求`0x18(%rax,%rcx,8)`的有效地址。若它出现在lea中，是否会读取该地址的内存？
- **D5-C2**：rax原值0xFFFFFFFF12345678，执行`movw $0xABCD,%ax`后是什么？另一次从原值重新开始，执行`movl $0xABCD,%eax`后是什么？

### D 控制流

- **D5-D1**：执行`cmpq %rsi,%rdi; setb %al`，对应的无符号关系是什么？若题目改为有符号的“小于”，应改用哪个set指令？
- **D5-D2**：下列按无符号64位计算的片段返回什么函数结果？输入n在rdi。

```asm
movq %rdi, %rcx
xorl %eax, %eax
.Lagain:
testq %rcx, %rcx
je .Ldone
addq %rcx, %rax
subq $1, %rcx
jmp .Lagain
.Ldone:
ret
```

请写出对应循环；计算n=4和n=0的结果。

### E 调用栈

- **D5-E1**：调用者准备执行call时rsp=0x700，下一条指令地址为0x401025。被调用者按顺序执行`pushq %rbx; subq $16,%rsp`。此时rsp是什么？保存的返回地址相对于当前rsp偏移多少？
- **D5-E2**：函数先用rbx保存一个稍后还要使用的值，然后调用另一个遵循ABI的函数。能否依赖调用后rbx仍保持原值？本函数自己改写rbx时，对它的调用者又有什么责任？

### F 数据布局

- **D5-F1**：`short a[4][6]`首地址0x5000，求`&a[3][2]`。写出乘的是列数还是行数。
- **D5-F2**：`struct T {char c; double d; int i;};`按本套约定，求成员偏移、整体对齐和总大小。

### G 联合与内存安全

- **D5-G1**：四个字节按地址升序为AA、BB、CC、DD，按小端unsigned int读取为何值？这是否等于把每个字节的数值相加？
- **D5-G2**：已把栈设置为不可执行，为什么仍应检查写入长度？请分别从数据正确性和返回到已有代码这两方面说明。

## 6 最终速查单

这里是最小通用版。考前再加入自己确实错过的规则，不扩成另一份长教材。

| 知识 | 最后核对 |
|---|---|
| 整数 | 先类型后运算；同一位模式可有不同解释；C有符号溢出不等于语言保证回绕 |
| 补码 | w位范围为−2^(w−1)到2^(w−1)−1；负值符号扩展补1 |
| 位移 | 先检查位宽、类型、移位量；负数算术右移的舍入方向与C除法可能不同 |
| 字节序 | 小端低地址放低位字节；画地址方向，不靠背字符串顺序 |
| 浮点 | 先分类再算E与M；exp不是E；非规格化没有隐藏1；中点取保留位末位为偶数的一侧 |
| 汇编 | AT&T源在前、目的在后；lea不读被计算地址的内存；写eax清rax高32位 |
| 条件 | cmp S,D看D−S；signed与unsigned分支不混用；cmov不自动让危险求值消失 |
| 循环 | 初始化、条件、更新、循环体四项；注意先测还是后测 |
| 过程 | call压下一条指令地址；ret弹地址；整数返回值常在rax；返回地址不是返回值 |
| 数组结构 | 元素大小×线性下标；每字段先对齐，结构整体最后再对齐 |
| 浮点代码 | 指针仍走通用寄存器；浮点参数走XMM；ss是单精度，sd是双精度 |
| 越界 | n个字符常需n+1字节；“没崩”不等于合法；各防护解决的问题不同 |

最后能够口头讲清：一道转换、一道舍入、一个条件分支、一张调用栈图、一个数组地址和一个结构体布局。本轮学习结束后，将真实的未解决问题写入对应的“第几讲后补充讲义”，不要把推测的弱点预填成记录。
