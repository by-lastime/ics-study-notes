## 每次处理顺序

1. 先在对话里直接回答问题，必要时补图、计算、例子或代码。
2. 查看现有补充文件和问答编号，判定是新问题还是已有问题的追问。
3. 新问题在本套资料中使用全局稳定编号Q001、Q002等；用现有最大编号加一。同一问题的追问保留在原编号下。
4. 保存提问日期（Asia/Shanghai）、用户原始问题、对应复习讲次和原课程或教材位置、整理后的解答。口语问题可加一句概括，但不替换原话。
5. 标明教材或课件内容与助手补充；能核实的页码才填写，印刷页和PDF页序分开，无法确认的写“待核实”。
6. 在主讲义的对应知识点附近加入补充链接，并更新本页问答目录。
7. 如果是更正错误，修正文并写简短更正记录，保留原问题；不覆盖无关已有内容。
8. 完成后告知收录文件和编号。用户明确要求不收录时，只回答，不写入。
