# 第5讲纠错题答案

对应[第5讲的新题库](../第5讲-完整测验与考前整理.md)。这些都是助手补充题。选择实际薄弱的两组验证，每题都要求结果与关键理由正确；不另虚构考试分值。

## A 整数与类型

**A1**：0x92无符号为146；8位补码值为146−256=−110；扩展成16位为0xFF92。符号扩展保留有符号数值，不是保留无符号解释。

**A2**：x转为32位unsigned，结果为2³²−3=4294967293，所以`x<u`为假。比较不是在数学整数−3与2之间直接进行。

## B 浮点

**B1**：`0 010 1000`阶码非零且非全1，是规格化数，E=2−3=−1，M=1.5，数值0.75。`0 000 0010`是非规格化数，E=1−3=−2，M=2/16=1/8，数值1/32。后一种没有隐藏的1。

**B2**：保留1.101，舍弃100，正好中点。保留的最低位是1，进位后为 **1.110**，最低位为0。不是总向下舍入，也不是把小数前三位101解释为十进制101后判断整体数值的奇偶。

## C 寻址与寄存器

**C1**：0x18+0x200+5×8=0x240。lea只计算这个数，不读0x240处的内存。

**C2**：写ax只替换低16位，结果 **0xFFFFFFFF1234ABCD**；写eax则清高32位，结果 **0x000000000000ABCD**。两问均从原值出发，不连续执行。

## D 控制流

**D1**：cmp计算rdi−rsi，setb表示无符号rdi<rsi。有符号小于改用 **setl**。不能把b与l理解为仅有拼写差异。

**D2**：对应的示意C为：

```c
unsigned long sum(unsigned long n) {
    unsigned long r=0;
    while (n!=0) {
        r+=n;
        n-=1;
    }
    return r;
}
```

n=4返回10，n=0返回0。这是先判断后执行的循环；若大n使和超出64位，则按无符号模2⁶⁴处理，不能无条件宣称数学和仍可精确表示。

## E 调用栈

**E1**：call后rsp=0x6F8；push后0x6F0；减16后 **0x6E0**。返回地址保存位置仍为0x6F8，所以相对当前rsp偏移 **0x18，即24字节**。保存的值是0x401025。

**E2**：可以依赖遵循ABI的被调用函数在返回时恢复rbx。它在执行中可以临时修改，不是硬件禁止写。本函数也必须为自己的调用者保留进入时的rbx，通常先保存，退出前恢复。角色是相对的：同一函数既可能是调用者，也可能是被调用者。

## F 数据布局

**F1**：一行六个short，偏移2×(3×6+2)=40=0x28，地址 **0x5028**。行号乘列数6。

**F2**：c偏移0，d偏移8，i偏移16；成员结束于20，整体对齐8，所以总大小 **24**。最后四字节是尾部填充。

## G 联合与内存安全

**G1**：小端结果 **0xDDCCBBAA**。低地址AA是低八位，其余字节有不同的位权；不是AA+BB+CC+DD。

**G2**：不可执行栈不会阻止越界写坏局部变量、指针或其他数据；若控制数据被破坏，还可能返回到原本就可执行的代码。NX限制在哪里取指令，不负责检查每次数组写入是否合法，所以仍需要长度检查等措施。
