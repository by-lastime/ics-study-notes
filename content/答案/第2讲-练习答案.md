## D2-P01　解码两个不同类别的数（4 分）

本题 $k=4,n=3$，Bias=$2^3-1=7$。

**`0x25`：**

1. `0x25 = 00100101₂ = 0 | 0100 | 101`。
2. $s=0$，$e=4$，$F=5$；阶码既非全 0，也非全 1，是规格化数。
3. $E=4-7=-3$，$M=1+5/8=13/8$。
4. $V=(13/8)2^{-3}=\boxed{13/64}$。

**`0x83`：**

1. `0x83 = 10000011₂ = 1 | 0000 | 011`。
2. $s=1$，$e=0$，$F=3\ne0$，是负的非规格化数。
3. $E=1-7=-6$，$M=3/8$，不能添隐藏的 1。
4. $V=-(3/8)2^{-6}=\boxed{-3/512}$。

评分：每个数 2 分，分段与类别 0.5 分，E、M 同时正确 0.5 分，最后数值 1 分。若第二问使用 $E=-7$ 或 $M=1+3/8$，分别属于“非规格化指数”和“隐藏位”错误，不是单纯算术失误。

## D2-P02　范围与特殊值（4 分）

$k=3,n=3$，Bias=3，最小规格化指数 $E_{\min}=1-3=-2$，最大有限指数 $E_{\max}=6-3=3$。

| 所问 | 字段 | 计算 | 答案 |
|---|---|---|---|
| 最小正非规格化数 | `0\|000\|001` | $2^{-3}\times2^{-2}$ | $\boxed{1/32}$ |
| 最小正规格化数 | `0\|001\|000` | $1\times2^{-2}$ | $\boxed{1/4}$ |
| 最大有限正数 | `0\|110\|111` | $(1+7/8)\times2^3$ | $\boxed{15}$ |
| `0\|111\|010` | 阶码全 1，frac 非零 | 不套有限数公式 | $\boxed{\mathrm{NaN}}$ |

评分：每项 1 分。前三项公式或字段依据 0.5 分、数值 0.5 分；最后一项类别 0.5 分、阶码与 frac 的判断依据 0.5 分。把最后一个数认成正无穷，是遗漏了“无穷还要求 frac 全 0”。

## D2-P03　中点与重新规格化（4 分）

本题格式 `1/4/3`，Bias=7。

**$21/4=5.25$：**

$$
5.25=101.01_2=1.0101_2\times2^2。
$$

保留三位 frac 后是 `1.010`，删掉的部分为 `1000...`，正好在 5 与 5.5 中间。保留末位是 0，所以不进位，舍成 $1.010_2\times2^2=5$。

$e=2+7=9=1001_2$，故结果为

```text
0 | 1001 | 010 = 01001010₂ = 0x4A
```

**$31/8=3.875$：**

$$
3.875=11.111_2=1.1111_2\times2^1。
$$

保留 `1.111`，删掉的也是中点模式 `1000...`，但保留末位为 1。这次必须进位成 `10.000₂×2¹`，重新规格化得到 `1.000₂×2²=4`。

$e=2+7=9=1001_2$，故结果为

```text
0 | 1001 | 000 = 01001000₂ = 0x48
```

评分：每问 2 分。精确二进制式 0.5 分，舍入判据与方向 0.5 分，最终数值 0.5 分，编码 0.5 分。第二问若写出进位但仍保留 E=1，则最后数值和编码相应扣分；这一处需要回看“重新规格化”，不必重学整套 IEEE 格式。

## D2-P04　数值转换（3 分）

1. **成立。** binary64 有 53 位有效精度，足以精确保存所有 32 位 int。转换为 double 没丢数值，再转回 int 也不会越界。因此 `x == (int)(double)x` 为真。结论 0.5 分、精度与范围理由 0.5 分。
2. $16777219=2^{24}+3$。binary32 在这个区间的间距为 2，邻近刻度是 $2^{24}+2=16777218$ 与 $2^{24}+4=16777220$，原数恰在中间。后者保留有效数的最低位为 0，所以舍成 $16777220$。再转回 int 不含小数也不越界，答案为 $\boxed{16777220}$。数值 0.5 分，间距、中点与偶数判据 0.5 分。这里“偶数”看目标格式的末位；两个十进制候选本身都是偶数，不能靠十进制奇偶选。
3. `(int)-6.75 =` $\boxed{-6}$，浮点到 int 在可表示范围内向零截断。数值 0.5 分、方向 0.5 分。回答 −7 是把向下取整混入了 C 转换。

## D2-P05　分别计算 CF 和 OF（4 分）

| 片段 | al 的最终值 | CF | ZF | SF | OF |
|---|---|---:|---:|---:|---:|
| A：`0x7f + 1` | `0x80` | 0 | 0 | 1 | 1 |
| B：`0x00 - 1` | `0xff` | 1 | 0 | 1 | 0 |

**A 的理由：**无符号 127+1=128，没有超出 8 位无符号范围，CF=0；补码的 127+1 超出最大值 127，结果位串为 `10000000`，表示 −128，OF=1。该位串非零、最高位为 1，所以 ZF=0、SF=1。

**B 的理由：**无符号 0 减 1 需要借位，CF=1；补码 0−1=−1 在范围内，OF=0。截断后的位串全 1，非零且最高位是 1，所以 ZF=0、SF=1。

评分：每段 2 分。al 0.5 分，CF 0.5 分，OF 0.5 分，ZF 与 SF 合计 0.5 分。只把溢出标志都写成 1，说明仍未把无符号范围与补码范围分开。

## D2-P06　选择 signed 与 unsigned 条件（3 分）

`cmpl %esi,%edi` 依据 **edi−esi** 设置标志，不改 edi、esi。

- 按补码解释：edi=−1，esi=1，−1<1，所以 `setl %al` 写入 $\boxed{1}$。
- 按无符号解释：edi=$2^{32}-1$，esi=1，前者并不小于后者，所以 `setb %al` 写入 $\boxed{0}$。

若用标志核对，32 位差为 `0xfffffffe`，CF=0、ZF=0、SF=1、OF=0。于是 signed 小于条件 SF≠OF 成立，unsigned 小于条件 CF 不成立。set 指令不修改这些标志，两次查看同一比较结果没有冲突。

评分：两个 set 结果各 1 分；解释比较次序并区分两种数值解释 1 分。仅说“setl 看有符号，setb 看无符号”而没有本题比较依据，解释项给 0.5 分。

## D2-P07　部分寄存器与条件码保持（3 分）

`testl %edi,%edi` 的按位与结果是 0，所以 CF=0、ZF=1、SF=0、OF=0。它不修改 edi，也不修改 rax。

`setne` 条件是 ZF=0。本题条件不成立，因此只把 al 改为 0。rax 的其余 56 位保持原值：

```text
执行 setne 后：rax = 0xaabbccddeeff0000
```

`movzbl %al,%eax` 将 0 零扩展到 32 位，写 eax 又清零 rax 的高 32 位：

```text
执行 movzbl 后：rax = 0x0000000000000000
```

两条指令都不改条件码，因此最终仍是 $\boxed{CF=0,\ ZF=1,\ SF=0,\ OF=0}$。在 setne 后高位仍有非零旧值，不能把整个 rax 当作整数 0。

评分：setne 后的完整 rax 1 分；movzbl 后的完整 rax 1 分；四个标志与保持原因合计 1 分。若只写 al=0，第一项只给 0.5 分，因为本题特意要求区分部分寄存器与完整寄存器。

## D2-P08　短分支的 C 与汇编对照（5 分）

`cmpq %rsi,%rdi` 比较 x−y；`jg .Lelse` 在 signed x>y 时跳到 else。因此不跳的路径是 x≤y，C 条件为：

```c
long choose(long x, long y) {
    if (x <= y) return x + 2;
    else return y - 1;
}
```

两个输入的追踪如下：

| x,y | 比较与跳转 | 执行的表达式 | 返回值 |
|---|---|---|---:|
| −3,2 | x>y 为假，不跳 | x+2 | −1 |
| 7,2 | x>y 为真，跳到 `.Lelse` | y−1 | 1 |

改成 unsigned long 比较时，需要在 unsigned x>y 时跳到 else，因此把 `jg` 换成 $\boxed{ja}$。题目仅改变比较类型；无符号加减本身按无符号运算规则解释。

不能把任意 `p ? *p : 0` 都改成先读 `*p` 再条件传送。当 p 为空时，原表达式不会解引用，提前读取却已经触发非法访问；后来选择 0 不能撤销这个访问。

评分：C 条件 1 分；两次返回值各 1 分；`ja` 1 分；指出提前解引用空指针的风险 1 分。最后一项只说“cmov 不一定好”没有说明原因不给分。

## D2-P09　选做：同样位数，不同有限实数数量（参考 5 分）

阶码全 1 的模式都留给无穷或 NaN，不属于有限值。其余 exp 一共有 $2^k-1$ 种，每个 exp 有 $2^n$ 种 frac，再乘两个符号，即有限位模式数量为：

$$
2(2^k-1)2^n。
$$

这些有限模式中，+0 与 −0 数值相同；其余正负有限数各有唯一模式。因此不同有限实数数量为 $2(2^k-1)2^n-1$。

- A：$2\times7\times8-1=\boxed{111}$。
- B：$2\times15\times4-1=\boxed{119}$。

最小正非规格化数是 $2^{1-\mathrm{Bias}-n}$：

- A：Bias=3，得到 $2^{-5}=\boxed{1/32}$。
- B：Bias=7，得到 $2^{-8}=\boxed{1/256}$。

B 的 frac 少一位，单个数量级的刻度较稀；但本题中可用阶码更多，且全 1 阶码占用的位模式更少，所以不同有限实数总数反而较多。这并不意味着 B 在每一个数附近都更精确。

参考评分：两种有限数数量各 1 分，说明排除全 1 阶码及两个零去重 1 分，两种最小正数各 1 分。

## D2-P10　选做：严格大小关系可能变成相等（参考 5 分）

原整数是 $a=2^{24}$，$b=2^{24}+1$，所以 a<b。

binary32 从 $2^{24}$ 开始相邻刻度间隔为 2。a 可精确表示；b 位于 $2^{24}$ 与 $2^{24}+2$ 的中间，最近偶数舍入选择前者。所以：

```text
(float)a = 16777216
(float)b = 16777216
```

浮点转换后的 `<` 为假，`==` 为真。若先分别转成 double，两者均可精确表示，仍保持 `<` 为真、`==` 为假。

这没有违反非严格单调性。非严格单调性只保证原来 a≤b 时，舍入后仍有 Round(a)≤Round(b)，允许两个不同输入变成相等。它并不保证严格小于关系一直保留。

参考评分：原整数关系 1 分，两个 float 数值和舍入依据 1 分，float 比较结论 1 分，double 结论及精确性 1 分，非严格单调性解释 1 分。
