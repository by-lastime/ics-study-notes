# 往年题筛选与使用说明

2026-10-07更新。用户已授权扩大历年题的收录范围：除2025第一次阶段测验继续保留外，其他年份只要在原课程前8讲范围内、有训练价值，都可选入。

本轮新增44题，直接来源为19份试卷文件，年份覆盖2012—2025。采用专题精选，不追求按年份平均取题。题面、独立解析已加入网站；另有可打印的题目册和解析册。旧五讲正文仍可按原顺序学习。

入口：[题目册](往年题精选-题目.md) · [独立解析](../答案/往年题精选-解析.md)。

## 选择原则

- 补充独立解题的变化：字节序混合转换、舍入中点、相对位移、跳转表、递归栈、声明与布局组合。
- 相同考点只保留有明显差异或组合价值的题，不把重复年份当作新知识。
- 老题IA32规则只有在明确给定、适合对照学习时保留；不混入当前x86-64默认前提。
- 原题有错或缺前提时，修正后标为改编，不把整理后的问法与答案冒充原卷原文或官方修订。原题自带正式更正则注明。
- 普通整数指令、程序控制与内存布局可入选；即便题目出现汇编，只要实际考Y86/HCL、流水线、缓存、链接、虚拟内存、进程或并发，本次仍排除。
- 本轮是44题精选，不是历年范围内所有小题的穷尽题库；检索到的其他同型题和未充分核实的题面不宣称已经收录。

## 特别处理的题面问题

- 2018期中异或交换题：采用原文件的后续答案修订。
- 2019期中掩码题：补上 `(ip & mask)` 的括号，避免C运算符优先级改变表达式含义。
- 2023期中lowbit题：指出x=0的边界，改用unsigned明确模运算。
- 2018期中union题：补齐大小端和char符号性，否则不能唯一回答。
- 2021期中二维数组题：在脱离选择项后只能求A的下界，不能错误声称A唯一。
- 2015期中结构体题：逐成员重算偏移，未沿用原解析中有误的填充字节叙述。
- 2025期末leave题：写明rsp是否额外改变，区分片段内等价写法与leave的一般语义。
- 2022期中完整switch题中有路径写入未定义的val/未经该路径初始化的rax。本轮不把该完整题作为有唯一数值输出的练习；改选2016期中完整switch，仍保留主讲义中已注明的简化改编。
- 2023期中未终止字符串题、旧题泛称“所有指令都改变标志”等有歧义内容，没有照搬进计分练习。
